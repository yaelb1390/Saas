Un asistente que responde sobre **tus propios documentos**: manuales, catálogos, políticas… lo que le subas.

Al subir un documento se trocea y se indexa para poder buscar dentro de él. Al preguntar, se recuperan los trozos que más se parecen a tu pregunta y se responde con ellos.

Ojo, no es lo mismo que la **ayuda del sistema**: esta pantalla sabe de tus documentos; la ayuda sabe cómo funciona el sistema.

> Eliminar un documento borra también sus fragmentos y no se puede deshacer: para recuperarlo habría que subirlo y reindexarlo.

Necesita una clave de API de OpenAI o Anthropic configurada para dar respuestas redactadas.
