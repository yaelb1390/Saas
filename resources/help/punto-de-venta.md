El punto de venta de mostrador, con lector de código de barras. Es el que se usa en colmados, ferreterías y tiendas.

## Cobrar

1. Escanea o busca el producto. Se puede buscar por nombre, código o SKU.
2. Ajusta cantidades si hace falta.
3. Pulsa **Cobrar**, elige la forma de pago y escribe con cuánto paga el cliente: el sistema calcula el cambio.

Si quieres emitir comprobante fiscal, pide la factura al cobrar: hace falta tener una secuencia de NCF vigente.

## Perfiles del negocio

En los ajustes del punto de venta puedes elegir el tipo de comercio (general, ropa, repuestos, salón, tecnología). Cada uno enciende lo que ese negocio suele necesitar: descuentos por línea, propina, número de serie, cantidades con decimales… y luego lo afinas interruptor a interruptor.

Necesitas un **turno de caja abierto** para cobrar.
